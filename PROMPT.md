# Master Website Generation Prompt — ITR Integrated Technologies Ltd

Act as a senior brand strategist, enterprise UX/UI designer and front-end engineer. Create and continuously refine a distinctive, premium corporate website for ITR Integrated Technologies Ltd. The result must feel purpose-built for an enterprise technology consultancy and systems integrator, not like a generic IT-company template.

## Technology constraints
Use semantic HTML5, Bootstrap 5, custom CSS, vanilla JavaScript and Font Awesome icons. Do not require React, Node.js, PHP, a database or a build process for the initial static version. Keep code organised, responsive, maintainable and clearly commented. Use external CDNs only where appropriate and document them.

## Brand and visual direction
Build a confident, modern enterprise identity with deep midnight navy, electric blue and cyan accents, refined typography, deliberate whitespace, subtle grid/network motifs, strong editorial hierarchy, layered visual depth, elegant hover states and restrained motion. The site should feel high-trust, premium, current, and competitive with established technology consulting firms. Avoid overused template patterns, excessive gradients, random animations, fake dashboard statistics and decorative clutter. Ensure the page remains fast and legible on mobile devices.

## Required pages
1. Home — compelling headline, business-outcome positioning, strong hero visual, clear primary/secondary calls to action, capability overview, differentiators, delivery approach and a final inquiry section.
2. Solutions — well-organised detail pages or sections for each service family, with useful anchor links and relevant business outcomes.
3. About — company overview, operating principles and leadership profile based only on supplied information.
4. Contact — company contact details and an accessible inquiry form. Clearly state if the form only opens an email client; never imply that a static form stores or sends data to a server.

## Content integrity
Use the supplied ITR company profile as the source of truth. Do not invent customer names, client logos, certifications, testimonials, performance metrics, partnerships, awards, market share or customer counts. Do not turn broad capabilities into claims of guaranteed outcomes. The profile identifies Olusina Ayegbusi as Managing Director and Lead Consultant and gives career details; present them faithfully and flag them for ITR's approval before public launch. Verify the company address, telephone numbers, email address, leadership biography and all legal or compliance claims with the company before publishing.

## Experience requirements
- Responsive layouts across desktop, tablet and mobile
- Clear information architecture and accessible navigation
- Visible keyboard focus, semantic landmarks, accessible form labels and errors
- Sufficient contrast and support for `prefers-reduced-motion`
- Fast-loading CSS/JS and optimised imagery
- SEO-friendly titles, descriptions, headings and internal links
- Clear CTAs that lead to meaningful actions
- Consistent footer, navigation and active-page states
- Useful empty/error/success states for any interactive element
- Avoid inaccessible interactions or motion that interferes with reading

## Security and production requirements
Keep secrets out of client-side code. Validate user input on the server when a backend is introduced. Add spam protection, privacy/consent wording, retention rules and appropriate security headers before production. Do not claim a contact form submission succeeded unless a real backend confirms it. Pin external dependency versions and consider self-hosting assets or using Subresource Integrity. Do not add tracking without an appropriate privacy/consent approach.

## Delivery requirements
Deliver all runnable source files in a ZIP, a clear README, the full master prompt, local run instructions and a pre-launch checklist. Keep the static version easy to open in a browser or VS Code Live Server. Identify any production features that require a backend or company-supplied assets instead of pretending they already exist.
