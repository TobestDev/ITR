# ITR Integrated Technologies — Corporate Website

Responsive multi-page corporate website concept built with HTML5, custom CSS, vanilla JavaScript, Bootstrap 5 and Font Awesome. No Node.js, PHP, database or build process is required.

## Pages
- `index.html` — premium homepage, capability overview and calls to action
- `solutions.html` — detailed capability areas and anchor links
- `about.html` — company overview and leadership profile
- `contact.html` — contact details and a front-end enquiry form that prepares an email in the visitor's default email application

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser, or use VS Code Live Server.
3. Internet access is needed for Bootstrap, Font Awesome and Google Fonts CDNs. Custom CSS and JavaScript are local.

## Before publishing
- Confirm company contact details, address and leadership biography.
- Replace the text-built ITR wordmark with the approved official logo if available.
- Add approved brand imagery, client logos, case studies, certifications and testimonials only after receiving permission and evidence.
- The contact form is a `mailto:` flow only; it does not store or submit data to a server. For production, connect it to a secure backend or approved form provider, add server-side validation, spam protection, consent/privacy wording and suitable data-retention controls.
- Review privacy, accessibility, SEO metadata, analytics consent and security headers for the hosting environment.
- Bootstrap, Font Awesome and Google Fonts load from public CDNs. Pin versions and use Subresource Integrity or self-host assets according to deployment/security policy.

## Design and content notes
The visual system uses deep navy, electric blue and cyan, enterprise typography, responsive layouts, custom visual motifs and restrained motion. Company service descriptions and the leadership summary are based on the provided ITR Profile PDF. No client logos, fabricated testimonials, invented performance statistics or unsupported customer counts have been added.
